ParseAnything

Document parser

Read a file. Keep the evidence.

Drop in a PDF, Word document, spreadsheet, slide deck, or a scan. You get the text in reading order, the regions on the page, Markdown, JSON, and the order in which each block precedes the next.

Presenting without a file?

  1. Reading The page, in the order it was written.
  2. Regions Each block, its page, and its box.
  3. Markdown A copy you can paste elsewhere.
  4. JSON The full result, including confidence and risk.
  5. Precedence Which block comes before which, and where it was read from.
